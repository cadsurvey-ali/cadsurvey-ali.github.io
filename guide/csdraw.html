Dual DrawCSDRAWالرسم بنظامينالرسم بنظامينDraw in two systems

ارسم بأوامر الأوتوكاد نفسها (POINT، LINE، PLINE، CIRCLE…) بإحداثيات تكتبها بأي نظام من نظامين الرسمة أو السايت، والنظام الثاني يتبعك لايف.

ارسم بأوامر أوتوكاد نفسها (POINT و LINE و PLINE و CIRCLE…) بإحداثيات تكتبها بأي من نظامَي الرسم أو الموقع، والنظام الآخر يتبعك مباشرة.

Draw with AutoCAD's own commands (POINT, LINE, PLINE, CIRCLE…) using coordinates typed in either system of the drawing or of a site; the other system follows live.

1شلون تشتغلطريقة العملHow it works

  1. انقر زر Dual Draw الصغير بلوحة Coordinates (جنب Quick Coord)، أو اكتب CSDRAW، أو زر ✎ Draw جنب السايت بـ Coord System.انقر زر Dual Draw الصغير في لوحة Coordinates (بجانب Quick Coord)، أو اكتب CSDRAW، أو زر ✎ Draw بجانب الموقع في Coord System.Click the small Dual Draw button in the Coordinates panel (next to Quick Coord), type CSDRAW, or ✎ Draw next to a site in Coord System.
  2. من القائمة فوگ اختار النظام: نظام الرسمة أو سايت مربوط بنظام. أسماء الخانات تتبع النظام (المحلي X / Y، والـ UTM E / N).من القائمة في الأعلى اختر النظام: نظام الرسم أو موقعًا مربوطًا بنظام. أسماء الخانات تتبع النظام (المحلي X / Y، و UTM E / N).In the list at the top choose the system: the drawing's system or a site linked to a system. The box names follow the system (local X / Y, UTM E / N).
  3. شغّل أي أمر بالأوتوكاد (POINT، LINE، PLINE، CIRCLE، MOVE…)، أو بدون أمر وتنرسم نقاط (POINT).شغّل أي أمر في أوتوكاد (POINT و LINE و PLINE و CIRCLE و MOVE…)، أو بدون أمر فتُرسم نقاط (POINT).Start any AutoCAD command (POINT, LINE, PLINE, CIRCLE, MOVE…), or none and points (POINT) are drawn.
  4. اكتب بأي صف: X ← Enter ← Y ← Enter (و Z إذا التك شغال) = النقطة تنزل، والخانات تفضى والمؤشر يرجع لـ X للنقطة الجاية.اكتب في أي صف: X ← Enter ← Y ← Enter (و Z إذا كانت علامة Z مفعّلة) = تنزل النقطة، وتفرغ الخانات ويعود المؤشر إلى X للنقطة التالية.Type in either row: X → Enter → Y → Enter (and Z when ticked) = the point goes in, the boxes clear and the cursor returns to X for the next point.
  5. خلصت؟ X فاضي + Enter = ينتهي الأمر.انتهيت؟ X فارغة + Enter = ينتهي الأمر.Done? Empty X + Enter = the command ends.

3الأمانالأمانSafety

  1. سايت مختار والنقطة طلعت برّا حدوده: سطر برتقالي وكارت، والرقم يتظلل حتى اللي تكتبه يحل محله. Enter مرة ثانية بنفس الأرقام = تنزل.موقع مختار والنقطة خارج حدوده: سطر برتقالي وبطاقة، ويُظلَّل الرقم ليحل محله ما تكتبه. و Enter مرة ثانية بالأرقام نفسها = تنزل.A site is chosen and the point falls outside it: an orange line and a card; the number is selected so what you type replaces it. Enter again with the same numbers = it goes in anyway.
  2. نظام الرسمة مختار وكتبت إحداثيات الرسمة لنقطة داخل سايت بنظامه: تنزل على طول ويا ملاحظة ℹ بس.نظام الرسم مختار وكتبت إحداثيات الرسم لنقطة داخل موقع له نظامه: تنزل مباشرة مع ملاحظة ℹ فقط.The drawing's system is chosen and you typed drawing coordinates for a point inside a site with its own system: it goes in at once, with an ℹ note only.
  3. النقاط المكتوبة تتجاهل السناب وتنزل على الأرقام بالضبط، بأي UCS.النقاط المكتوبة تتجاهل الالتقاط (OSNAP) وتنزل على الأرقام تمامًا، في أي UCS.Typed points ignore object snaps and land exactly on the numbers, in any UCS.
أداة PRO: تحتاج Pro أو فترة التجربة. تتذكر النظام والتك Z ومكانها على الشاشة.أداة PRO: تحتاج إلى Pro أو فترة التجربة. وتتذكر النظام وعلامة Z ومكانها على الشاشة.A PRO tool: needs Pro or the trial. It remembers the system, the Z tick and its place on the screen.
