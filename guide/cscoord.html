Coord SystemCSCOORDنظام الإحداثيات والسايتاتنظام الإحداثيات والمواقعCoordinate system & sites

رسمة وحدة بنظام إحداثيات رئيسي، ولحد 10 سايتات كل واحد بنظامه. ترسم حدود السايت مرة وحدة وتربطه بنظامه، وكل نقطة تنقرها بأي أداة تنحسب بنظام السايت اللي هي بيه.

رسم واحد بنظام إحداثيات رئيسي، وحتى 10 مواقع لكل منها نظامه. ترسم حدود الموقع مرة واحدة وتربطه بنظامه، فتُحسب كل نقطة تنقرها في أي أداة بنظام الموقع الذي تقع فيه.

One drawing, one main coordinate system, plus up to 10 sites each with its own system. Draw a site's boundary once and link it to its system: every point clicked in any tool is worked out with the system of the site it falls in.

1شلون تشتغلطريقة العملHow it works

  1. انقر زر الكرة Coord System بلوحة Coordinates (أو اكتب CSCOORD، أو الحلقة السادسة بصفحة My Profile).انقر زر الكرة Coord System في لوحة Coordinates (أو اكتب CSCOORD، أو الحلقة السادسة في صفحة My Profile).Click the globe Coord System in the Coordinates panel (or type CSCOORD, or the 6th ring on the My Profile page).
  2. النظام الرئيسي: اختار نظام محفوظ من القائمة، أو New system….النظام الرئيسي: اختر نظامًا محفوظًا من القائمة، أو New system….Main system: choose a saved system from the list, or New system….
  3. السايتات: ارسم حدود كل مشروع بولي لاين مغلق، وانقر + Site، واكتب الاسم وانقر الحدود.المواقع: ارسم حدود كل مشروع خطًا متعددًا مغلقًا، وانقر + Site، واكتب الاسم وانقر الحدود.Sites: draw each project's boundary as a closed polyline, click + Site, type the name and click the boundary.
  4. اختار السايت وانقر System… حتى تربطه بنظامه.اختر الموقع وانقر System… لربطه بنظامه.Select the site and click System… to link it to its own system.
  5. خلصت: كل الأدوات (CLABEL، Quick Coord، CGRID، CBM، GEOUTM، Dual Draw…) تتبع أنظمة الرسمة وحدها.انتهيت: جميع الأدوات (CLABEL و Quick Coord و CGRID و CBM و GEOUTM و Dual Draw…) تتبع أنظمة الرسم تلقائيًا.Done: every tool (CLABEL, Quick Coord, CGRID, CBM, GEOUTM, Dual Draw…) follows the drawing's systems by itself.

3أزرار السايتاتأزرار المواقعSite buttons

+ Site
سايت جديد: الاسم ثم انقر حدوده. سايت وحد بكل نقرة. الحدود اللي تتداخل ويا سايت ثاني تنرفض.موقع جديد: الاسم ثم انقر حدوده. موقع واحد في كل مرة. وتُرفض الحدود المتداخلة مع موقع آخر.A new site: name, then click its boundary. One site per click. A boundary overlapping another site is refused.
System…
يربط السايت بنظامه (أي وقت). السايت اللي بعده ما مربوط يبين برتقالي.يربط الموقع بنظامه (في أي وقت). ويظهر الموقع غير المربوط باللون البرتقالي.Links the site to its system (any time). A site not linked yet shows orange.
View
كارت للقراءة بس بنظام السايت، وبيه Pick a point للفحص.بطاقة للقراءة فقط بنظام الموقع، وفيها Pick a point للفحص.A read-only card of the site's system, with Pick a point to test it.
✎ Draw
يفتح Dual Draw على هذا السايت مباشرة.يفتح Dual Draw على هذا الموقع مباشرة.Opens Dual Draw already on this site.
Rename · Colour · Zoom
تغيير الاسم، ولون الحدود (نفس اللون يطلع بفلاتر الجداول)، والتقريب على السايت.تغيير الاسم، ولون الحدود (يظهر اللون نفسه في فلاتر الجداول)، والتقريب إلى الموقع.Rename, the boundary colour (the same colour shows on the table filters), and zoom to the site.
☑
التك جنب السايت: مطفي = إحداثي واحد بس داخله (بدون النظام الثاني).علامة الاختيار بجانب الموقع: إطفاؤها = إحداثي واحد فقط داخله (بلا النظام الثاني).The tick next to a site: off = one coordinate only inside it (no second system).
⠿
اسحب السايت فوگ أو جوه حتى تغيّر الترتيب.اسحب الموقع للأعلى أو الأسفل لتغيير الترتيب.Drag a site up or down to change the order.

4التنبيهاتالتنبيهاتWarnings

  1. نقطة داخل سايت بدون نظام: حلقة برتقالية تومض على النقطة، وكارت مرة وحدة لكل سايت ويا زر Coord System للتصليح. النقطة تنحسب بالنظام الرئيسي.نقطة داخل موقع بلا نظام: حلقة برتقالية تومض على النقطة، وبطاقة مرة واحدة لكل موقع مع زر Coord System للتصحيح. وتُحسب النقطة بالنظام الرئيسي.A point inside a site with no system: an orange ring flashes on the point and one card per site, with a Coord System button to fix it. The point uses the main system.
  2. نقطة على الحدود بالضبط (سناب على الزاوية): تنحسب بالنظام الرئيسي ويطلع كارت مرة وحدة.نقطة على الحدود تمامًا (التقاط على الزاوية): تُحسب بالنظام الرئيسي وتظهر بطاقة مرة واحدة.A point exactly on a boundary (snapped to a corner): uses the main system, with a card once.

5الجداول والليبلاتالجداول والكتاباتTables and labels

  1. بـ CLABEL و CBM وقائمة GEOUTM: القائمة مجمّعة حسب النظام، بيها عمود System، وفوگها أزرار فلتر بلون كل سايت وعدد نقاطه. الفلتر يقرر شنو يطلع: Table و Copy و Excel و PDF و CSV و KML.في CLABEL و CBM وقائمة GEOUTM: القائمة مجمّعة حسب النظام، وفيها عمود System، وفوقها أزرار فلترة بلون كل موقع وعدد نقاطه. والفلتر يحدد ما يخرج: Table و Copy و Excel و PDF و CSV و KML.In CLABEL, CBM and the GEOUTM list: the list is grouped by system, with a System column and filter chips in each site's colour with its point count. The filter decides what goes out: Table, Copy, Excel, PDF, CSV, KML.
  2. الليبل يكتب اسم النظام الثاني بسطر لوحده فوگ إحداثياته. المحلي يكتب X / Y، والـ UTM يكتب E / N.يكتب الليبل اسم النظام الثاني في سطر مستقل فوق إحداثياته. المحلي يُكتب X / Y، و UTM يُكتب E / N.Labels write the second system's name on its own line above its coordinates. Local is written X / Y, UTM E / N.
  3. CGRID: الشبكة داخل سايت تاخذ نظام السايت. الإطار اللي يقطع سايتين: بدون شبكة ثانية، ارسم شبكة لكل سايت.CGRID: الشبكة داخل موقع تأخذ نظام الموقع. والإطار الذي يقطع موقعين: بلا شبكة ثانية، ارسم شبكة لكل موقع.CGRID: a grid inside a site takes the site's system. A frame crossing two sites: no second grid; draw one grid per site.
كل شي ينحفظ ويا الرسمة نفسها، فإذا بعثت الرسمة لزميلك تروح الأنظمة والسايتات وياها.يُحفظ كل شيء داخل الرسم نفسه، فإذا أرسلت الرسم لزميلك انتقلت الأنظمة والمواقع معه.Everything is saved inside the drawing itself: send the drawing to a colleague and the systems and sites go with it.
