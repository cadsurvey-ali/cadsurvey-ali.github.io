Import PointsCPOINTSإدراج نقاط من ملفإدراج نقاط من ملفPoints from a file

تختار ملف نقاط (TXT أو CSV أو Excel، أو ملفات الأجهزة: Leica GSI و XYZ و Topcon PNT و ASC)، الأداة تعرف الأعمدة وحدها، تشوف معاينة، وبضغطة وحدة تنرسم النقاط ويا كتاباتها (الاسم، المنسوب، الكود ...) مرتبة جنب كل نقطة، وكل نوع كتابة على لير خاص. أداة مجانية.

اختر ملف نقاط (TXT أو CSV أو Excel، أو ملفات أجهزة المساحة: Leica GSI و XYZ و Topcon PNT و ASC)، فتتعرّف الأداة على الأعمدة تلقائيًا، وتعرض معاينة، ثم تُرسم النقاط بنقرة واحدة مع كتاباتها (الاسم، والمنسوب، والرمز ...) مرتبةً بجانب كل نقطة، وكل نوع من الكتابة على طبقة خاصة. أداة مجانية.

Choose a points file (TXT, CSV or Excel, or instrument files: Leica GSI, XYZ, Topcon PNT, ASC), the tool finds the columns by itself, you check a preview, and one click draws the points with their texts (name, level, code ...) neatly next to each point, each kind of text on its own layer. A free tool.

أول شي من أسماء العناوين: E / X / EAST / EASTING، N / Y / NORTH / NORTHING، Z / H / ELEV / LEVEL / RL، POINT / PT / NAME / ID / NO، CODE / FEATURE، DESC / DESCRIPTION / REMARK. إذا ماكو عناوين، من الأرقام: E و N هم الأرقام الكبيرة (بالـ UTM الـ E تقريباً 6 مراتب والـ N تقريباً 7، فإذا الملف بيه N قبل E تنعرف وتتبدل وحدها)، والـ Z رقم صغير بعدهم، واسم النقطة نص أو رقم صحيح قبلهم، وأول عمود نص باقي يصير Code.

أولًا من أسماء العناوين: E / X / EAST / EASTING، N / Y / NORTH / NORTHING، Z / H / ELEV / LEVEL / RL، POINT / PT / NAME / ID / NO، CODE / FEATURE، DESC / DESCRIPTION / REMARK. وإذا لم توجد عناوين، فمن الأرقام: E و N هما الرقمان الكبيران (في UTM يتكوّن E من نحو 6 مراتب صحيحة و N من نحو 7، لذا يُكتشف الملف الذي فيه N قبل E ويُبدَّل تلقائيًا)، و Z رقم صغير بعدهما، واسم النقطة نص أو عدد صحيح قبلهما، وأول عمود نصي متبقٍّ يصبح Code.

First by the header names: E / X / EAST / EASTING, N / Y / NORTH / NORTHING, Z / H / ELEV / LEVEL / RL, POINT / PT / NAME / ID / NO, CODE / FEATURE, DESC / DESCRIPTION / REMARK. Without a header, by the numbers: E and N are the big numbers (in UTM, E has about 6 digits and N about 7, so a file with N before E is found and swapped by itself), Z is a small number after them, the point name is text or a whole number before them, and the first text column left becomes Code.
