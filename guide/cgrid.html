Coord GridCGRIDشبكة الإحداثياتشبكة الإحداثياتCoordinate grid

يرسم شبكة إحداثيات بالـ Model أو داخل Viewport: خطوط أو علامات + بالتقاطعات أو شرطات على الإطار، ويا كتابات E و N، ونظام ثاني اختياري (مثلاً نظام المحطة). كل شبكة تحتفظ بإعداداتها، وأي تغيير بالنافذة يعدّل الشبكة الفعّالة مباشرة.

ترسم شبكة إحداثيات في الـ Model أو داخل Viewport: خطوطًا أو علامات + عند التقاطعات أو شرطات على الإطار، مع كتابات E و N، ونظامًا ثانيًا اختياريًا (مثل نظام المحطة). تحتفظ كل شبكة بإعداداتها، وأي تغيير في النافذة يعدّل الشبكة الفعّالة مباشرة.

Draws a coordinate grid in model space or inside a viewport: lines, + crosses at the intersections or ticks on the frame, with E / N labels and an optional second system (for example the plant system). Each grid keeps its own settings, and any change in the palette edits the active grid at once.

3نظام ثانينظام ثانٍSecond system

تگدر تضيف شبكة ثانية (X / Y) لنظام محلي فوگ الشبكة الأساسية. فعّل Use a second coordinate system بقسم Second system واختار الطريقة:

يمكنك إضافة شبكة ثانية (X / Y) لنظام محلي فوق الشبكة الأساسية. فعّل Use a second coordinate system في قسم Second system واختر الطريقة:

You can add a second grid (X / Y) of a local system over the main one. Tick Use a second coordinate system in Second system and choose the method:

One point (offset)
نقطة وحدة معروفة بالنظامين وبدون دوران: نفس خطوط الشبكة تاخذ الرقمين (مثلاً E 724100 وتحته Plant X 1080).نقطة واحدة معروفة في النظامين من دون دوران: تحمل خطوط الشبكة نفسها الرقمين معًا (مثلًا E 724100 وتحته Plant X 1080).One point known in both systems, no rotation: the same grid lines get both numbers (for example E 724100 with Plant X 1080 under it).
Two points
نقطتين معروفات بالنظامين: يحسب الدوران والمقياس، والنظام الثاني ياخذ شبكة خاصة بيه.نقطتان معروفتان في النظامين: يُحسب الدوران والمقياس، وتُرسم للنظام الثاني شبكة خاصة به.Two points known in both systems: the rotation and scale are worked out, and the second system gets its own grid.
Point + angle
نقطة وحدة وزاوية الدوران (° عكس عقارب الساعة، من الرسم للنظام الثاني).نقطة واحدة وزاوية الدوران (° عكس اتجاه عقارب الساعة، من الرسم إلى النظام الثاني).One point and the rotation angle (° counter-clockwise, from the drawing to the second system).
Point 1 · Point 2 · Pick
لكل نقطة: E / N بالرسم ← E / N بالنظام الثاني. Pick ياخذ إحداثيات الرسم بتأشيرة.لكل نقطة: E / N في الرسم ← E / N في النظام الثاني. يأخذ Pick إحداثيات الرسم بنقرة.For each point: drawing E / N → second-system E / N. Pick takes the drawing coordinates with a click.
Name · Colour · Text
بادئة قبل X / Y (مثل Plant)، لون الخطوط وشفافيتها ولون الكتابة، وارتفاع كتابته. تحتها سطر يكتب الدوران والمقياس المحسوبة.بادئة قبل X / Y (مثل Plant)، ولون الخطوط وشفافيتها ولون الكتابة، وارتفاع كتابته. وتحتها سطر يعرض الدوران والمقياس المحسوبين.A prefix before X / Y (such as Plant), the line colour, its transparency and the text colour, and its text height. Under them a line shows the rotation and scale found.
Its grid
لمن اكو دوران: خطوط أو + أو شرطات للشبكة الثانية، ونوع خطها (مثلاً DASHED) ومقياسه، وحجم علامتها.عند وجود دوران: خطوط أو علامات + أو شرطات للشبكة الثانية، ونوع خطها (مثل DASHED) ومقياسه، وحجم علامتها.When there is a rotation: lines, crosses or ticks for the second grid, its line type (e.g. DASHED) and scale, and its cross size.
