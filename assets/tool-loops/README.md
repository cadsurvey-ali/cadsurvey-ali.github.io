# tool-loops — لقطات حركة حقيقية لكل أداة (من شات الفيديوهات CT)
- لكل أداة 3 ملفات: <CMD>.webm (VP9) · <CMD>.mp4 (H.264) · <CMD>.jpg (poster)
- 960×540 (16:9) · 24fps · بدون صوت · 6–7 ثواني · تعيد نفسها بدون قفزة (crossfade بالنهاية)
- manifest.json بيه الاسم والمدة لكل أداة
- الاستخدام المقترح: <video autoplay muted loop playsinline preload="none" poster="CMD.jpg"><source src="CMD.webm" type="video/webm"><source src="CMD.mp4" type="video/mp4"></video>
- الموجود هسه (8): CLEAD · CPOINTS · CGRID · OINFO · ANUM · CAREA · CLEN · PTX — من الدروس الحقيقية
- الباقي ينضاف لما علي يسجّل دروس/ريلات الأدوات الثانية
